# 云序工作室管理系统（本地版）

参考原站页面构建的工作室管理系统：
前端原样复用 layui 2.11 + layuiAdmin(iframe 版) 的页面与脚本，后端用 **Python Flask + SQLite** 重新实现了全部接口。

## 外部接口接入状态（2026-09-24）

- 企业微信群机器人：后台“订单群消息推送”填写客户内部群 Webhook 后，新订单和状态变更会按规则推送；列表显示最近发送结果，失败可重试。只有企业微信官方机器人地址可保存。
- 淘宝、闲鱼、拼多多、京东、抖音、快手、小红书：店铺页面可保存客户自己的阿奇索应用及店铺令牌；保存后仍为“待接口授权与联调”。需要客户提供七平台的实际权限、接口文档和店铺授权，不能沿用原平台 AppId 或调用量。
- 支付宝：客户的商户应用、商家转账产品和密钥尚未配置，在线打款保持关闭；线下结算可继续使用。账号登记不会产生支付宝官方授权。
- 正式对外事件回调需要 HTTPS 域名；目前尚未提供域名，不启用阿奇索订单事件推送。

详细边界见 `docs/superpowers/specs/2026-09-24-external-integrations-design.md`。

## 启动

```bash
cd suqing-admin
python app.py
```

- 浏览器打开 <http://127.0.0.1:8100>
- 初始账号 `1234567890` / 密码 `394607`（系统管理员，与原站一致）
- 其它演示账号：`boss/123456`（老板）、`kf小晴/123456`（客服）、`ds星尘/123456`（打手）、`cw01/123456`（财务）、`tz01/123456`（团长）
- 首次启动自动生成 `data/app.db` 并写入示例数据（游戏、项目、160 笔订单、客户、人员、排团、账本…）；删除 `data/app.db` 可重新生成
- 依赖：Python 3.10+；使用 `pip install -r requirements.txt` 安装。Windows 上的 `启动.bat` 会优先使用项目内 `.venv`。
- 开发模式：`python app.py --dev`（改代码自动重启，页面 JS 报错回传到 `/api/DevApi/JsErrors`；`/api/DevApi/LoginAs?acc=登录账号&to=/System/systemsetting` 可免密切换账号核对各角色界面，仅开发模式可用）
- 环境变量：`PORT`（端口，默认 8100）、`HOST`（默认 127.0.0.1）、`SQ_SECRET`（会话密钥）
- 邮箱找回需配置 `SQ_SMTP_HOST`、`SQ_SMTP_FROM`，可选 `SQ_SMTP_PORT`（默认 465）、`SQ_SMTP_USER`、`SQ_SMTP_PASSWORD`；465 使用 SSL，其它端口使用 STARTTLS。未配置时不生成验证码，也不会在服务器日志打印验证码。

### 安全配置与数据保管

- 页面会自动获得会话绑定的 CSRF 令牌；后台 layui AJAX 和客户端 `/app/` API 会自动携带令牌。升级后请刷新已打开的页面。无令牌的旧脚本请求会返回 403。
- 游戏密码、号库机密字段、店铺 AppSecret/AccessToken 和企业微信群机器人 Webhook 会在 SQLite 中加密；首次运行自动生成 `data/field.key`，也可通过 `SQ_DATA_KEY` 提供 Fernet 密钥。**丢失或更换密钥将无法读取已有密文。** 备份 `data/app.db` 时必须同时安全备份此密钥，并避免把两者一起公开。
- 旧数据库的明文字段会在首次启动时迁移，并整理 SQLite 页面。迁移前的加密备份保存在 `data/pre-security-20260923.db.enc`，恢复时需要相同的字段密钥。
- 新上传保存在 `data/uploads/public/` 或 `data/uploads/private/`；私有文件必须通过登录后访问，旧的 `/upload/文件名` 链接也会按引用用途判断权限。备份数据库时还应备份 `data/uploads/`。
- 文件上传上限为 10 MB，整次请求上限为 12 MB；仅接受经过内容检查的图片及指定文档类型。
- 公网部署仍需更改所有演示账号密码、使用正式 WSGI 服务与 HTTPS。设置 `SQ_PUBLIC=1`、`SQ_SECRET` 和 `SQ_TRUSTED_HOSTS`（逗号分隔的域名）；公开模式会启用 Secure Cookie，并拒绝缺少会话密钥或可信域名的启动。登录错误按账号和 IP 在 15 分钟窗口内限流。`python app.py` 是本地开发启动方式。

## 客户端 APP（手机 / 电脑自适应）

- 入口：<http://127.0.0.1:8100/app/>（安卓安装包加载此页面；手机浏览器也可预览，电脑宽度 ≥960px 使用 PC 客户端布局，覆盖浏览、搜索、商城、报价、下单、订单/会话、账户与权益；小于 960px 保持手机布局。此客户端不是微信小程序）
- 安卓安装包：[android/dist/yunxu-client-1.0.0.apk](android/dist/yunxu-client-1.0.0.apk)。首次打开填写可从手机访问的后台网址；局域网启动方式、重新打包和签名密钥备份说明见 [android/README.md](android/README.md)。
- 安卓 APP 直接加载本系统的 `/app/` 前台，并使用 `/api/client/*` 接口；无需微信小程序 AppID、OpenID 或小程序支付配置。后台“客户端内容管理”沿用原站的 `/System/wechatappmange` 路径及部分 `GetWechatApp...` 接口名，改名会影响现有管理脚本，因此仅更新展示名称。
- 代码：`static/app/`（`index.html` 壳、`app.js` 路由与全局状态、`pages.js` 全部页面、`app.css` 样式、`lib/` 本地化的 Vue 3 + vue-router）+ 后端 `api/client.py`（`/api/client/*`）
- 功能：手机号注册/登录（邀请码、协议勾选）→ 首页（搜索、活动倒计时、Banner/公告、游戏、分类专区、热门套餐）→ 游戏项目 / 套餐商品 / **自助报价器**（选段位算价直接下单）→ 下单（常用角色一键带入、区服/角色/账号，自动算会员折扣、满减、抵扣券，余额支付或联系客服付款）→ 我的订单（进度、订单会话、确认验收、评价、售后申请、再来一单、撤单退款）→ 个人中心（余额明细、积分商城、抽奖、优惠券、我的游戏角色、邀请有礼、售后记录、打手风采、消息通知、会员等级、常见问题、在线客服、深色模式/字号、协议与隐私、注销账号）
- 后台对应新增页面：订单管理 → **客户评价**（回复客户）、**售后处理**（处理/退款到余额）；系统维护 → **客户端设置**（新客券、邀请奖励、首页活动位、用户协议/隐私政策）
- 与后台的关系：客户 = 后台“会员管理”里的会员；客户端订单进后台“订单管理”（来源“客户端下单”，客服收到站内消息）；后台改状态客户端即时收到通知；积分商品/兑换发货/抽奖奖品/满减/会员折扣/公告 Banner 全部在后台“客户端内容管理”里维护；客户留言进客服的“我的消息”
- 客户忘记密码：短信通道接上之前，由客服在“会员管理 → 编辑”里填“客户端密码”重置
- 开发模式辅助：`/api/DevApi/LoginAsCustomer?no=会员号`（或 `phone=`）免密以某会员身份打开客户端

## 与原站的差异

- 与外部平台对接的功能（淘宝/拼多多店铺、交易平台发单、短信通道、支付宝在线结算、虚拟号码、微信公众号/小程序、鸡蛋铺账号绑定、电子合同、实名认证、IM 内部沟通）界面保留、设置可保存，但不会真正外发，接口返回“本地版未接入”提示
- 消息推送：原站用 WebSocket，本地改为主框架每 10 秒轮询本人未读消息（`static/JS2019/local_msg_poll.js`）：新订单/客户留言/售后/评价到达时右上角弹提示 + 提示音 + 浏览器通知，并自动刷新已打开的订单类列表（不会关闭正在操作的弹窗）；客户端 /app 每 30 秒刷新未读、会话页 15 秒刷新
- 抓取页面里写死的默认查询日期（抓取日 2026-09-19）已改为相对“今天”（`dago(n)`），新单默认就在列表范围内
- 抓取时原站里的租户隐私（店主手机号、支付宝账号、真实 IP/地理位置、客户资料）均已清除，不在本项目中
- 权限：角色的菜单权限用菜单 key 存储，主框架按权限隐藏菜单；打手只能看到自己接手的订单
- 图片上传保存到 `static/upload/`（原站为阿里云 OSS）
- 排团详情、游戏号详情两个弹窗原站只抓到空壳（当时无记录），本地按自己的数据模型重写（`tools/hand_templates/Group/GroupDetails*.html`、`patch_templates.py` 21f）
- 报价器：原站的段位阶梯数据无法抓取（原站已宣布下线该功能），本地按各游戏公开的段位体系内置了 20 款游戏的阶梯（`api/pricecalc.py` 的 `LADDERS`），王者荣耀自动生成，其它游戏在“通用报价设置”里点“初始化数据”；计价规则：整段价格 ÷ 该段星数 × 跨越星数，再叠加利润率、苹果区浮动、铭文区间、套餐浮动、首单特价（支持 `{price}` / `{project}` 变量）与挽留折扣
- 客户填单：生成的链接指向本地公开页 `/Public/WriteOrder?key=…`，客户提交后按“填单设置”显示提示语/图片，并可进入 `/Public/SearchOrder` 查订单进度（只展示状态变化，不暴露打手、接单价等内部信息）
