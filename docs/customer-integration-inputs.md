# 客户自有外部服务接入资料

本项目不使用原“素晴一号”平台的 AppId、调用量、余额或支付宝授权。请由客户作为商户完成以下申请。密钥、令牌和 Webhook 不要发在聊天里，也不要提交到 Git。

## 1. 七个平台店铺：阿奇索

七个平台是淘宝、闲鱼、拼多多、京东、抖音、快手、小红书。

1. 在 [阿奇索开放平台](https://open.agiso.com/) 注册并完成资质认证，创建客户自己的电商业务应用。
2. 向阿奇索申请这七个平台需要的订单查询、订单事件、虚拟发货及状态查询权限。不同平台支持的能力以实际批复为准。
3. 每个店铺分别授权客户应用，取得该店铺的 AccessToken。后台“淘宝店铺接口”及“其他电商平台接口”中填写 AppId、AppSecret、AccessToken；页面不会回显密钥。
4. 提供阿奇索交付的七平台接口文档：网关 HTTPS 地址、接口路径、请求参数、返回样例、权限清单、调用量查询方式、事件验签和重试规则。现有公开文档只有通用签名方式，不能据此猜测七个平台的订单接口。

参考：[创建应用说明](https://www.agiso.com/detail/1552)、[推送权限说明](https://www.agiso.com/detail/1806)。

## 2. 支付宝在线结算

1. 客户在 [支付宝开放平台](https://open.alipay.com/module/webApp) 创建并上线自己的网页/移动应用，申请商家转账产品及实际所需额度和收款场景。
2. 提供应用 AppId、商户身份、当前产品 API 文档及产品开通状态；应用私钥、支付宝公钥及证书通过服务器安全配置交付。不要把私钥填进后台备注或聊天。
3. 核对 2026-09-20 的 [API 商家转账产品升级通知](https://open.alipay.com/notice)，确认客户应用应使用的当前接口和签约条件后，再启用真实打款。未完成前仅使用线下结算。

## 3. 企业微信群机器人

客户在企业微信内部群创建群机器人，复制官方 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...` 地址，在后台“订单群消息推送”配置游戏、触发时机和 Webhook。当前程序会在新订单录入或状态变更时发送；列表显示最近结果，失败可手动重试。配置前不会发送。

## 4. 正式 HTTPS 域名

如果启用阿奇索订单事件推送、支付宝异步通知或供外部访问的客户前台，提供正式 HTTPS 域名和反向代理部署信息。本机 `127.0.0.1` 无法作为平台回调地址。
