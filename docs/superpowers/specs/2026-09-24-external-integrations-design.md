# 云序工作室外部接口接入设计

## 目标与边界

接入客户自行申请并授权的淘宝、闲鱼、拼多多、京东、抖音、快手、小红书店铺，客户自己的支付宝商家转账应用，以及企业微信群机器人。原“素晴一号”系统的 AppId、授权码、余额和支付宝授权不属于本地系统，不迁移、不调用。后台仅在实际授权和调用成功后显示“可用”。

## 服务拆分

### 电商

优先通过客户新申请的阿奇索开放平台电商业务应用接入七个平台。每个店铺单独保存平台、店铺标识、订单来源、AccessToken 和授权状态；应用密钥与店铺 Token 加密落库，列表和日志只返回遮盖值。对外请求由服务端统一签名、限时和限制域名。订单读取以平台+店铺+外部订单号定位，查询成功后只映射订单价、付款状态、留言和买家标识等实际返回字段。自动发货由订单状态流触发，先写幂等任务记录，再请求平台，最终记录平台回执；不根据本地状态直接宣称发货成功。七平台的具体接口路径、字段和权限以客户取得的阿奇索接口文档为准，未获得文档或权限的平台保持“待接入”，不发送猜测请求。

### 支付宝结算

客户须在支付宝开放平台创建并上线自己的应用，签约商家转账产品。服务端使用客户的 AppId、应用私钥、支付宝公钥及必要证书调用官方接口。付款人确认账单后生成唯一商户单号，先检查权限、余额和收款信息，再发起转账；不确定结果必须查询，不允许重复转账。只有官方返回最终成功才将账单标记为已支付。任何密钥和完整收款账号均不进入日志或前端列表。没有产品权限和密钥时仅提供现有线下结算。

### 企业微信群推送

管理员在已有页面配置内部群机器人 Webhook、游戏和触发时机。只允许企业微信官方机器人域名；Webhook 加密存储、列表遮盖。订单发到内部抢单大厅或外部交易平台时生成一条幂等通知任务，服务端发送并记录成功/失败，失败可重试，不能因为通知失败回滚订单业务。历史“启用”配置须在有效 Webhook 存在时才视为可用；内部群聊 ID 不是企业微信 Webhook。

## 状态、错误与安全

- 统一状态：未配置、待授权、可用、调用失败、权限不足；状态来自授权检查和实际调用结果。
- 删除模板中写死的 37864 次；未接到官方配额接口时显示“以服务商后台为准”。
- 密钥保存需加密并只允许管理员写入；修改时留空表示保持旧值；接口响应和异常不得回显密钥。
- 外部调用配置超时、幂等键和可查询的操作记录。付款与发货不得盲目自动重试。
- 未提供客户授权资料或正式 HTTPS 域名时，代码可部署为未激活状态，不能假装已经开通。

## 客户需提供

1. 阿奇索开发者应用、七个平台对应店铺授权和官方接口文档/权限；若需要事件推送，还需正式 HTTPS 回调地址。
2. 支付宝商家转账产品开通证明、应用配置和证书/公钥；密钥通过服务器安全配置提交，不放在聊天或源码。
3. 企业微信内部群机器人的 Webhook。

## 完成判定

每项服务都显示真实配置及授权状态。电商订单查询和发货只在有实际平台回执时成功；支付宝账单只在官方确认转账成功时结算；群通知有真实发送回执。没有授权的服务明确显示待配置，不能返回模拟成功。
